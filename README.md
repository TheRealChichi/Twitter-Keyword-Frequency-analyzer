# Real-Time Twitter Keyword Frequency Analyzer

This project analyzes and counts keyword frequencies from Twitter data using Python. Built for the EEE-5513 Software Development for Artificial Intelligence course, it focuses on extracting insights from social media text using NLP and data analysis tools.

## Features

- Read and process tweet data from `.csv` or `.sqlite` databases
- Count keyword frequencies in real-time or batch mode
- Display keyword trends and generate summary statistics
- Simple interface using Jupyter Notebook

## Technologies Used

- Python
- pandas
- sqlite3
- Jupyter Notebook
- CSV / SQL data processing
- Natural Language Processing (basic tokenization and filtering)

## Files

- `keywordcountfinal.ipynb`: Main notebook containing the implementation
- `Tweets.csv`: Sample tweet dataset in CSV format
- `database.sqlite`: Sample SQLite database of tweets
- `requirements.txt`: List of Python packages used

## How to Run

1. Clone the repo:
   ```bash
   git clone https://github.com/yourusername/twitter-keyword-frequency-analyzer.git
   ````

2. Install dependencies:
pip install -r requirements.txt

3.. Open and run the notebook:
jupyter notebook keywordcountfinal.ipynb
